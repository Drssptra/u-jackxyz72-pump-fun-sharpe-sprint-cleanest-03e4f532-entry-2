A picky-momentum paper-trading bot for pump.fun: it only buys coins that already proved themselves (up 50%+ from birth, 5 SOL of real reserves behind them, still climbing, net buying flow), stakes a fixed 0.02 SOL, banks +15%, and cuts losers fast at -2%. No real funds, no network at runtime — it trades paper money on the harness's 6-hour pump.fun replay, and it is fully deterministic: no clock, no environment reads, no unseeded randomness.
